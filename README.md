# Exame Final - Programação Funcional (BCC222)

Este repositório contém as resoluções para o exame final da disciplina de Programação Funcional, utilizando a linguagem Haskell.

## Estrutura do Projeto

Cada arquivo `questao*.hs` corresponde à solução de uma questão do exame.

- **[questao1.hs](questao1.hs):** Avalia o resultado de uma expressão que envolve comparação de strings e casamento de padrões.
- **[questao2.hs](questao2.hs):** Implementa a função `contem`, que verifica se todos os elementos de uma lista estão contidos em outra.
- **[questao3.hs](questao3.hs):** Calcula o conceito de um aluno com base em notas ponderadas, interagindo com o usuário para obter os valores.
- **[questao4.hs](questao4.hs):** Contém a função `empates` para calcular o número de jogos empatados por um time em um campeonato.
- **[questao5.hs](questao5.hs):** Define a typeclass `YesNo` e várias instâncias para simular um comportamento booleano em diferentes tipos.
- **[questao6.hs](questao6.hs):** Define um tipo de árvore `Arv a` e implementa uma instância de `Functor` para ela.
- **[mensagemSecreta.hs](mensagemSecreta.hs):** Decodifica e exibe uma mensagem a partir de uma lista de códigos
